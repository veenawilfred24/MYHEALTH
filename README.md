## MYHealth — LLM-Powered Medical Records Platform

A web application built to digitize and manage patient medical records,
with AI-powered report summarization and health Q&A.

### Tech Stack
- Backend: Python, Flask
- Database: MongoDB, GridFS (for large files)
- AI Integration: Meta Llama 70B via GroqAPI
- Frontend: HTML, CSS

### Features
- Digitize patient records, prescriptions, and reports
- AI-generated summaries of medical reports
- Retrieval-grounded health Q&A chatbot

### Context
Built as MSc Data Science capstone project at Christ University (Jun–Sep 2024).
Demonstrated to faculty panel as final deliverable.
